# LocalForge AI Phase 1

## Scope

Phase 1 establishes the runnable application foundation:

- FastAPI backend
- React and TypeScript frontend
- Environment-driven configuration
- Ollama connection configuration
- Health endpoint
- Professional IDE-style shell
- Backend tests
- Frontend type checking and production build

## Deferred

The following are intentionally deferred:

- Agent orchestration
- Repository indexing
- File editing
- Diff approval
- Terminal execution
- Permission policies
- SQLite persistence
- WebSockets
- Git integration
- Browser automation
- MCP integration
- Project memory
